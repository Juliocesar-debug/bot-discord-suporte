# 🛠️ Discord Ticket & Support Bot

Um bot de atendimento e suporte automatizado para Discord, desenvolvido em Node.js e Discord.js v14. Permite a abertura de tickets privados por categoria, gerenciamento de permissões dinâmicas e painel interativo.

## 🚀 Funcionalidades

- 📩 **Painel Interativo:** Seleção de categoria por menu dropdown.
- 🔒 **Canais Privados:** Criação automática de salas exclusivas entre o utilizador e a equipa de suporte.
- 🛡️ **Controlo de Permissões:** Restrição de visualização para membros que não pertençam ao ticket.
- 🔔 **Notificações:** Botão para alertar a equipa sobre chamados pendentes.
- 🧹 **Encerramento Automático:** Eliminação programada do canal ao fechar o atendimento.

## 🛠️ Tecnologias Utilizadas

- **Node.js**
- **Discord.js v14**
- **JavaScript (ES6+)**
